# Hi, I'm Lee

**Podcaster. Plex enthusiast. Accidental developer.**

I'm one of the voices behind **The XboxCast**, where we talk Xbox, gaming,
and whatever else inevitably derails the conversation.

When I'm not podcasting, I'm usually tinkering with my Plex server,
self-hosting something, or finding another problem that didn't really
need solving.

That last one got slightly out of hand and became **MyCouch**.

## MyCouch

[MyCouch](https://github.com/MyCouchApp/MyCouch) is my self-hosted Plex
companion for exploring your media library, viewing history, server stats,
and figuring out what to watch next.

**Your media. Your history. What's next?**

What started as a tool for my own Plex server somehow became a real
open-source project. Apparently I make software now.
